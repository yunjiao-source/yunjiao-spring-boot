# examples

示例项目

## example-apijson-fastjson2

基于`starter-apijson-fastjson2`示例项目。在启动项目之前，需要配置数据库，并运行脚本，具体查看`resources`目录。
成功启动服务后，就可以访问服务提供的接口。在doc/apijson下，有apifox，postman工具文件。

## example-apijson-gson

基于`starter-apijson-gson`示例项目。在启动项目之前，需要配置数据库，并运行脚本，具体查看`resources`目录。
成功启动服务后，就可以访问服务提供的接口。在doc/apijson下，有apifox，postman工具文件。

** 注意
在服务启动过程中，会出现异常，这是因为官方提供的gson插件还存在问题。有些接口请求也会出现异常
